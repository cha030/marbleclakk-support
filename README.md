## Publish using GitHub Pages

Upload `index.html` to the **root** of the [`cha030/marbleclakk-support`](https://github.com/cha030/marbleclakk-support) repository (with this README, optionally).

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the **main** branch and **/(root)** folder, then **Save**.
4. After publishing, visit <https://cha030.github.io/marbleclakk-support/>.
5. Confirm that both languages and email links work correctly.

**App Store Connect Support URL (after GitHub Pages is live):** `https://cha030.github.io/marbleclakk-support/`

The site is plain HTML/CSS. No JavaScript, no images, and no external hosting dependencies are needed.

This repository is for support only; do not change the original web game or the iOS app repository.
